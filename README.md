# Murmure

Client du réseau social Murmure, transformé en application Android (APK) par GitHub Actions.

- Les fichiers du site : `index.html`, `style.css`, `app.js`, `config.js`
- Adresse du serveur : à modifier dans `config.js`
- L'APK se génère dans l'onglet **Actions** > « Build APK » > **Artifacts** > `murmure-apk`
